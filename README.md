# Vizsgaútvonalak – Kozma u. 3 (F/BP/289–306)

Interactive map of the motorcycle exam routes, built from OpenStreetMap data.

- `index.html` – the map page
- `data/` – OSM extract, refreshed weekly by `.github/workflows/update-osm.yml`
- `queries/` – the Overpass queries the workflow runs

Map data © OpenStreetMap contributors, ODbL.
